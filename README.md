# Carte interactive — Clients Authôt

Carte interactive présentant les collectivités et institutions qui utilisent Authôt.

## Usage

⚠️ Cette carte est destinée **uniquement** au site internet d'Authôt. Toute autre utilisation, rediffusion ou réutilisation est interdite sans autorisation explicite.

## Affichage

La carte est publiée via GitHub Pages et s'affiche à l'adresse :

https://oursapp-dev.github.io/carte-interactive/

Elle peut être intégrée au site d'Authôt au moyen d'une iframe :

```html
<iframe
  src="https://oursapp-dev.github.io/carte-interactive/"
  width="860" height="820"
  style="border:0; max-width:100%;"
  title="Carte clients Authôt"
  loading="lazy"></iframe>
```
